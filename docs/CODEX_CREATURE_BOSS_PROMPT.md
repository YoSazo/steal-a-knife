# Codex brief: the creature bosses (zones 2-8)

## Where things stand

Every zone's boss is a round character (Frank, Ivy, Sam, Leo, Ruby, Kate, Zoe, Nick) asleep in front
of a graveyard of coffins, Steal an Egg style. We're replacing those people with **creatures**, like
Steal an Egg's guardians (Chicken, Swan, Scorpion, Tiger, Yeti, Cerberus, T-Rex).

Zone 1's creature is **done**: your Courtyard hedge hound (`src/shared/Assets/HedgeHound.luau` +
`src/shared/Config/ToyGeometry/HedgeHound.luau`, built by `tools/build_hedge_hound.py`). Claude wired
it in and it works end to end (sleeps, wakes, chases with a real trot, catches, goes back to sleep).
It's switched off for now (Frank is back) so that **all eight creatures go live together**.

**Your job: the other seven creatures, zones 2-8.** Art only, exactly like the hound. Claude wires
each one in (one line in `GameConfig.Zones[i].Creature` + one entry in GuardService's
`CREATURE_MODULES`). Don't touch game code.

## The contract (copy the hedge hound - it's proven)

For each creature `<Name>` deliver two files:

1. `src/shared/Config/ToyGeometry/<Name>.luau` (generated by a `tools/build_<name>.py`):
   ```lua
   return {
       StandHeight = <studs, standing>,
       Joints = { -- per joint group: its pivot in model space, asleep and awake
           Body = { Awake = CFrame.new(...), Asleep = CFrame.new(...) },
           Head = { ... }, Tail = { ... },
           LegFrontLeft = { ... }, LegFrontRight = { ... }, LegBackLeft = { ... }, LegBackRight = { ... },
       },
       Blocks = { { Name, Group, Role, State ("Both"/"Awake"/"Asleep"), Size, Offset, Color, Angle, Neon }, ... },
   }
   ```
2. `src/shared/Assets/<Name>.luau` with the same three functions as `HedgeHound.luau`:
   - `Build(parent, frame, pose) -> Model` (Root part at floor level under the torso, `PrimaryPart` =
     Root, model attributes `FrontAxis = "-Z"`, `StandHeight`, `ArtOnly = true`, `Zone = <i>`)
   - `SetPose(model, "Asleep" | "Waking" | "Awake", blend?)` (blend 0..1 for Waking)
   - `SetRunPhase(model, phase)` (reference only; our run cycle is in GuardService)

The simplest path: copy `HedgeHound.luau` and the build script, swap the geometry.

### What our code relies on (please keep these exact)

- **Joint group names.** The run cycle (GuardService `animateHoundRun`) swings every group whose
  name starts with `Leg`: `LegFrontLeft` + `LegBackRight` swing together, the other two opposite
  (a diagonal trot). It wags `Tail` side to side. It leans and bounces the whole model.
  - Four legs: use the four names above.
  - **Two legs** (a bird, a dino, a yeti): name them `LegFrontLeft` and `LegFrontRight` so they
    alternate. Leave out the back two.
  - No legs (a ghost, a slime): skip the Leg groups; tell us and we'll give it a glide or hop.
  - Wings, arms, tentacles: their own groups (e.g. `WingLeft`, `ArmRight`). They're posed by
    `SetPose` like everything else. Tell us which ones should flap; we'll animate them.
- **A `Head` joint group** must exist. We attach the name tag, the "!" alert and the sleeping "Zzz"
  to it.
- **Eyes:** `Role = "EyeLeft"` / `"EyeRight"`, closed asleep and bright Neon awake (as the hound).
- **Root at floor level**, centred under the body (the hound's is). We place the model by its pivot.
- **No** Humanoid, scripts, lights, physics or particles in the model (we add effects).

## Size and part count

- Bigger as you go deeper. Zone 2 about 14 studs standing (the hound is 13); the Cosmic boss about
  22-24. Roughly +1.5 studs a zone. A player is about 5 studs.
- A few hundred parts each, like the hound. These run on phones.

## Style (same as the hound and everything else)

Toy-block, flat bright colours, chunky simple shapes (Block/Wedge/Ball/Cylinder), no smooth sculpted
surfaces, no gore. Cute-scary: instantly readable from across the runway, clearly a threat when
awake. Sleeping = curled/lying, eyes shut. Awake = standing tall, head up, eyes lit.

## The seven creatures

Each one should match its biome (the zone's floor/wall colours are in `MapService` `ZONE_FLOORS` /
`ZONE_WALLS`) and get scarier with rarity. These are suggestions; better ideas welcome, as long as
each reads at a glance.

|---|---|---|---|
| 2 | The Gardens, Rare | Ivy, The Gardener | A giant **flower-backed toad** (lily pad green, a big bloom on its back) |
| 3 | The Crypts, Epic | Sam, The Gravedigger | A **skeleton hound / bone wolf** (bone white on grey stone, purple eyes) |
| 4 | The Catacombs, Legendary | Leo, The Collector | A **sand scorpion** with a gold-banded tail (sandstone + gold) |
| 5 | The Inferno, Mythic | Ruby, The Firestarter | A **lava salamander / small dragon** (red rock, glowing orange cracks) |

| 7 | The Heavens, Celestial | Zoe, The Angel | A **winged pegasus / sky lion** (cloud white, pale blue, gold halo) |
| 8 | Outer Space, Cosmic | Nick, The Void Walker | A **void beast** (deep purple, star-speckled, many glowing eyes) |

## Deliverable per creature

1. The two Luau files (and the build script).
2. A note: Root height relative to the ground, standing height in studs, and any non-leg groups that
   should animate (wings, arms).
3. Renders: front + three-quarter, asleep and awake, ideally one next to a 5-stud player block for
   scale.

Deliver them one at a time if that's easier; we'll wire each in Studio as it arrives and switch all
eight on together at the end.
